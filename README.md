# Sistema de Login Completo

Sistema de login com cadastro de usuário utilizando HTML, CSS e JavaScript.

## Funcionalidades
- Cadastro de usuário
- Login com validação
- Armazenamento de dados com localStorage
- Redirecionamento após login

## Tecnologias
- HTML
- CSS
- JavaScript

## Objetivo
Projeto desenvolvido para praticar autenticação básica e manipulação do DOM.

## Como usar
1. Abra o index.html
2. Crie uma conta
3. Faça login

## Observação
Este projeto não utiliza banco de dados real, sendo apenas para fins de estudo.
